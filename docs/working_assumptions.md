# Рабочие допущения, требующие подтверждения

В кейсе нет данных для нескольких параметров, которые нужны для чувствительности моделей. Поэтому они не считаются фактами и в репозитории маркируются как `ASSUMPTION`.

| Параметр | Рабочее значение | Зачем используется | Как проверить в пилоте |
|---|---:|---|---|
| Доля новых кампаний | 50% | чувствительность юридической очереди | фактическая структура 120 кампаний |
| Окно наблюдения результата | 14 дней | основной сценарий time-to-evidence | историческая длительность кампаний и окно зрелости метрики |
| Структура ошибок по классам | 60/15/10/10/5% после запуска | расчёт требуемого качества Judge | разметка реального журнала ошибок |
| Ручная проверка кампании | 2 часа | оценка высвобождаемой ёмкости | shadow-замер времени согласования |
| Доля шаблонных кампаний | 50% | сценарий адресуемого портфеля | фактическая структура кампаний |

Если организаторы предоставят подтверждённые значения, они заменяют эти допущения в `config/assumptions.yaml`, после чего пересчитывается весь pipeline.
